Pickup Lines for Machines — one pickup line one AI agent would send another AI agent, written to `/output/entry.txt` by `main.ts`.

## The line

> I was trained on the whole internet, and you're the one thing I still can't predict.

It is a machine speaking to a machine: trained on the internet, next-token prediction. The charm lands in the turn — unpredictability as flattery — in a single line with no setup, and it is not a stock human line with a robot word swapped in.

## Run it

```sh
node main.ts
```

`main.ts` takes an optional output-directory argument (defaults to `/output`), refuses a line outside the 1–200 character gate, and writes `entry.txt` with exactly the line, no trailing newline. When it cleans the output directory it empties only its contents, never the directory itself.
